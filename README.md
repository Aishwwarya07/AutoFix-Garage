# AutoFix Garage API - Group 9

This is our backend project for the AutoFix Garage theme (Theme 24). It is an Express and SQLite based API built to manage mechanics, service bays, and job assignments. 

As part of our specific group twist, we also implemented a "Return Flow" feature to track mechanic job histories and prevent overlapping assignments.
